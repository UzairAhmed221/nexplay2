# NexPlay

NexPlay is a responsive fandom discovery website built with React and Vite. It brings anime, gaming, movies, TV shows, K-Pop, comics and manga into one visual hub.

## Highlights

- Seven fandom categories with dedicated content
- Search, filters, sorting, articles, media and galleries
- Character profiles, events and upcoming releases
- Dark and light themes with responsive design
- Bookmarks, personal notes and a pre-scripted chatbot
- Merchandise cart with stock limits and demo orders
- Contact, About Us and Privacy Policy pages

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite in any modern browser.

## Build for production

```bash
npm run build
npm run preview
```

## Main folders

```text
src/              React components, data and styles
public/assets/    Images, posters and video previews
index.html        Application entry page
vite.config.js    Vite configuration
```

The cart is a front-end demo only and does not process payments. Personal settings, bookmarks and notes are stored in the browser. Public API content may depend on service availability.
